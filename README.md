# Drey's Recipe Book — ITE 10 Practical Exercise 5

A beginner-friendly multi-page recipe website built with HTML.

## Pages
- `index.html` — homepage, recipe cards, kitchen measurement table, feedback form, and video element.
- `recipes/adobo.html` — Chicken Adobo recipe.
- `recipes/pasta.html` — Garlic Butter Pasta recipe.
- `recipes/pancakes.html` — Fluffy Pancakes recipe.

## Features
- Semantic HTML structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Three individual recipe pages in addition to the homepage
- Ordered and unordered lists
- Images with descriptive alternative text
- A data table with caption and header scopes
- A feedback form with labels and appropriate input types
- HTML video element with fallback text
- Responsive CSS and visible keyboard focus styles

## How to view
Open `index.html` in a web browser. Keep the `recipes` folder and `styles.css` in their original locations.
